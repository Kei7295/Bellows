# 路线图

路线图表达方向，不构成交付承诺。BETA 期间的优先级以 Issue 与安全/稳定性问题为准。

## v0.0.1 BETA（当前）

已完成：本机工作台、实例管理、OneBot v11 反向 WS、消息控制台、人格/Provider/记忆管理、演示管线、日志审计、SQLite 持久化。
未完成：Tauri 壳、真实 LLM、插件运行时、正向 WS/HTTP、钥匙串、向量记忆、MCP、调度器。

## v0.0.2 — 稳定化

- 修复 BETA 反馈中的缺陷，补齐消息分页与检索体验
- 演示管线可开关；实例重启后状态恢复更可靠
- API 契约冻结前补齐错误码与请求校验
- CI 覆盖 OneBot 事件解析的更多用例

## v0.1.0 — 真实推理

- Provider 真实请求（OpenAI 兼容 / 本地推理）与流式输出
- 人格与记忆注入上下文，提示词可编辑
- 密钥存储方案（钥匙串或加密文件），不再只存 `secret_ref`

## v0.2.0 — 插件与扩展

- 插件运行时（加载、权限、沙箱边界）
- 插件市场安装/更新
- 正向 WS / HTTP 接入

## v0.3.0 — 桌面与记忆

- Tauri 桌面壳与安装包
- 自动记忆抽取与检索
- 调度器与定时任务

## 长期

- 多平台适配（不限于 QQ）
- 可观测性（结构化日志、指标导出）
- 国际化
